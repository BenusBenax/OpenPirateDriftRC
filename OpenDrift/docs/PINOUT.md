# Pinout / Распиновка — PirateDriftRC (headless)

Целевая плата: **ESP32-C3 devkitm-1** (RISC-V, 4 MB flash)

Две прошивки (два варианта приёмника):
- **`esp32_headless`** — обычное PWM-радио (GPIO20/21).
- **`esp32_headless_crsf`** — приёмник **ExpressLRS / ELRS** (CRSF-протокол по UART на GPIO20/21).

> Все сигнальные пины — 3.3 В логика. Серво/ESC/IMU питаются **внешним** источником
> или от соответствующего контакта платы, НЕ от GPIO. Обязателен общий GND.
> Питание 5 В для серво/ESC подаётся отдельно.

---

# Сборка PWM-радио — `esp32_headless`

## Подключение (кратко)

| Компонент | Пин ESP32-C3 | Куда на устройстве |
|-----------|--------------|--------------------|
| **MPU6050 SDA** | GPIO6 | SDA модуля GY-521 |
| **MPU6050 SCL** | GPIO7 | SCL модуля GY-521 |
| **MPU6050 VCC** | 3.3V | VCC модуля |
| **MPU6050 GND** | GND | GND модуля |
| **Серво рулевое** | GPIO2 | сигнальный провод серво |
| **Сервопривод (+/-)** | внешний 5V / GND | питание серво |
| **Радио-вход РУЛЕНИЕ (PWM)** | GPIO20 | выход руления приёмника |
| **Радио-вход ГАЗ (PWM)** | GPIO21 | выход газа приёмника |
| **Радио GND** | GND | общий GND приёмника |
| **Мотор/ESC (тест, Web)** | GPIO1 | сигнал ESC (см. ниже) |
| **USB** | USB-C | прошивка + Serial (115200) |

# Сборка ELRS / CRSF — `esp32_headless_crsf`

Приёмник **ExpressLRS** подключается по UART (CRSF-протокол)— это цифровой линк, у приёмника
должен быть режим **CRSF** (чаще всего UART 400k CRSF). Руление/газ/усиление приходят
каналом CRSF, отдельные PWM-входы не нужны.

## Подключение (кратко)

| Компонент | Пин ESP32-C3 | Куда на устройстве |
|-----------|--------------|--------------------|
| **MPU6050 SDA** | GPIO6 | SDA модуля GY-521 |
| **MPU6050 SCL** | GPIO7 | SCL модуля GY-521 |
| **MPU6050 VCC** | 3.3V | VCC модуля |
| **MPU6050 GND** | GND | GND модуля |
| **Серво рулевое** | GPIO0 | сигнальный провод серво |
| **Сервопривод (+/-)** | внешний 5V / GND | питание серво |
| **ELRS приёмник RX (в плату)** | GPIO20 | CRSF-выход приёмника |
| **ELRS приёмник TX (в плату)** | GPIO21 | вход для телеметрии приёмника |
| **ELRS приёмник GND** | GND | общий GND приёмника |
| **ESC / мотор** | GPIO1 | сигнал ESC (выход газа 50 Гц) |
| **ESC питание** | батарея (+/-) | общий GND с платой |
| **USB** | USB-C | прошивка + Serial (115200) |

### Важно для ELRS
- Каналы CRSF: **1 — руление**, **2 — газ**, **3 — усиление (gain)** (`CRSF_STEERING_CHANNEL=0`,
  `CRSF_THROTTLE_CHANNEL=1`, `CRSF_GAIN_CHANNEL=2`).
- Газ (ESC) начинает выдаваться только после **удержания нейтраля (1500 мкс) минимум 0.5 c** —
  это защита от случайного пуска мотора.
- Каналы 1–16 можно зеркалить на GPIO через веб-конфигуратор (блок «Auxiliary Channel Outputs»,
  только в AMOLED-сборках), либо настраивать параметры через встроенный CRSF device (EdgeTX).

# Общие разделы

## IMU — MPU6050 (I2C, адрес 0x68)
Определено в `lib/IMU/IMU.h` (`SDA_PIN = 6`, `SCL_PIN = 7` для headless):
- **GPIO6 = SDA**, **GPIO7 = SCL**
- Доп. подтяжки на плате уже включены кодом (INPUT_PULLUP), отдельные резисторы не обязательны.
- Если модуль не найден — в headless-сборке работа продолжается **без IMU** (гироскоп отключается).

## Рулевое серво
- PWM-сборка: **GPIO2**; ELRS/CRSF-сборка: **GPIO0** (`SERVO_OUTPUT_PIN` в `src/main.cpp`).
- Частота 50 Гц (или 250/333 по настройке `controlLoopHz`).
- Диапазон импульсов 900–2100 мкс (физические ограничения), рабочий 1000–2000 мкс.
- Питание серво — **внешний 5V**, общий GND с платой.

## Мотор/ESC (Web-тест) — GPIO1
`SHARED_GAIN_THROTTLE_PIN = 1` в PWM-сборке; в ELRS-сборке это `CRSF_THROTTLE_OUTPUT_PIN = 1`:
- При тесте мотора из веб-интерфейса (`Test Motor`) пин **временно** используется как
  выход PWM 50 Гц на ESC. ESC мотора подключается сигналом именно сюда.
- ESC запитан **внешне** (например, от батареи), общий GND с платой обязателен.
- ⚠️ Тест гоняет мотор 1500→2000→1000→1500 мкс — снимите колёса/проп.

## Тест серво (Web)
Кнопка `Test Servo` в веб-интерфейсе гоняет рулевое серво (на пине серво вашей сборки)
по циклу 1500→2000→1000→1500 мкс. Гиро/радио/ESC-вывод на время теста блокируются.

## Примечания
- Serial идёт через нативный USB (CDC), поэтому в любой сборке GPIO20/GPIO21 свободны под приёмник.
- Точка доступа Wi-Fi: `PirateDriftRC` (пароль по умолчанию `piratedrift`).
- Сборка и загрузка ELRS-версии:
  ```bash
  pio run -e esp32_headless_crsf
  pio run -e esp32_headless_crsf -t upload
  ```
- Пин мотора можно сменить: в обоих вызовах `webConfig.begin(...)` в `src/main.cpp`
  аргумент `SHARED_GAIN_THROTTLE_PIN` → желаемый GPIO.
